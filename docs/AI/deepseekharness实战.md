## 安装&启动

### 安装
```bash
npm install -g @deepseek-ai/dsh
```

### 查看版本号
```bash
dsh --version
```

### 启动
```bash
dsh web
```

### 安装插件市场
```bash
dsh plugin --profile web add dshmarket
```

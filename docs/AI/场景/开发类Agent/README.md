# 概览

一般这类Agent都需要当场搭建。目前的做法就是：
1. 为项目搭建一个**Harness 项目**，该项目存放Agent的skill、prompt、**记忆**、文档等等。
2. 在Harness中安装开发相关的skill（如superpowers）
3. 让Agent阅读项目源码，并生成项目的编码规范、项目业务概览、第三方系统交互等的**知识库**
4. 定义Agent的开发流程
   - 需求开发：完整的开发流程。需求文档-->生成设计文档-->生成详细设计文档-->文档审查-->实施-->单测...其实就是superpowers那一套，当然也可以按需自定义
   - BUG修复：工单驱动，主要是能根据工单输出详设文档，其它都一致。

## 注意点

- 需要指明开发/修复环境
- 开发完成后不要自动提交到GIT，而是由用户Code Review后再提交
- 需求、设计、详设文档，需要按需求号整理好

## 难点

1. 开发流程的优化

- 开发完成后，如何实现自动化前后端联调？
- 如何做到真正的自动化？（仅输入需求文档，则可将详设+开发+测试+部署流程跑通）

2. Agent自进化

- 如何实现Agent的记忆模块？
- 如何让Agent拥有归纳总结反省的能力，能将自己的错误，以及新的成功的解决方案总结成经验的能力。
